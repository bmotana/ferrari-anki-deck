polished draft

- **Source**: Wikipedia as primary (the List of Ferrari vehicles page is your anchor—it links out to every individual model page). "Maybe other" stays open as a *phase 2* enrichment step once Wikipedia's gaps become visible—it's better to scrape one source cleanly first than try to merge two sources blind.
- **Data scope**: road/production models only — this excludes F1 cars, prototypes that-never-shipped, and one-offs, which simplifies things a lot since Wikipedia's list page already separates these reasonably well.
- **Output**: two CSVs from one scrape run —
    - `ferrari_anki.csv` → just `front` (image) and `back` (model name + year, since "name" alone is ambiguous across decades — e.g., there are multiple "Ferrari 250" variants)
    - `ferrari_kaggle.csv` → name, year(s) of production, engine, body style, number produced, image URL/licence, source URL — whatever Wikipedia's infoboxes reliably give you
